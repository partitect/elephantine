Engine Capabilities

Engineered for Sovereign, High-Speed Agents

Everything needed for agents that run continuously without forgetting, drifting, or leaking private data.

Zero-GPU ONNX Embeddings

Powered by quantized ONNX models running natively on CPU using AVX-512 instructions. No CUDA drivers, no GPU cloud bills, instant sub-5ms vector generation.

Embedded LanceDB & SQLite WAL

Zero external dependencies. LanceDB provides columnar, disk-backed vector search while SQLite WAL guarantees ACID compliance for audit trails and agent states.

Role-Authority Consensus

Stops agent drift and contradictory memory. Assign hierarchical authority levels (e.g. Lead > Worker) so lower-ranked subagents cannot hallucinate over verified facts.

Native Model Context Protocol

Plug-and-play MCP server for Cursor, Claude Desktop, Antigravity, and any MCP-compliant client. FastMCP standard with zero configuration.

Live WebUI Memory Inspector

Built-in dashboard at /dashboard to inspect semantic vector spaces, visualize memory graphs, verify scopes, and edit facts in real time.

Total Data Sovereignty

Your agents' secrets, customer conversations, and internal proprietary workflows never leave your local machines or private enterprise VPC.

Works Out-of-the-Box with Codex, Cursor, Claude, & Antigravity

Elephantine speaks the universal Model Context Protocol. Seamlessly integrates with the world's leading agentic IDEs — from OpenAI Codex and Cursor to Claude Desktop and Antigravity. Once installed, your IDE agent instantly acquires three high-level cognitive memory primitives:

remember_fact (scope, key, value, authority, confidence)

Stores verified knowledge into LanceDB and writes to SQLite audit log.

recall_context (query, scope, top_k, min_confidence)

Cosine similarity semantic search using local AVX-512 embeddings.

get_procedural_workflow (workflow_id)

Retrieves deterministic multi-step recipes executed by specialized agents.
